# 中文冒险岛 · Chinese Adventure Lab · V1.1

## 快速开始 / How to run

### 单设备复习和小游戏
直接在浏览器打开 `index.html`。朗读、词汇匹配、竞速问答和谁是卧底可以离线使用。

### 真正多人「你画我猜」（教师 + 多名学生，各自一台设备）
1. 在有 Node.js 18+ 的教师电脑打开这个项目文件夹，在终端运行：`node server.js`。无需安装第三方依赖。
2. 教师浏览器打开 `http://localhost:3000/multiplayer.html`，选择课程并创建房间。
3. 让学生连接与教师相同的**受信任 Wi-Fi**，浏览器打开 `http://教师电脑的局域网IP:3000/multiplayer.html`（例如 `http://192.168.1.20:3000/multiplayer.html`）。若不能访问，检查防火墙及学校网络的设备间隔离策略。
4. 学生填写六位房间码及**非真实姓名的课堂昵称**。教师选择「四选一」或「输入中文」，点击开始。
5. 系统每轮按加入次序轮流指定一位画画者，只有画画者屏幕显示秘密词语并可画画；其余人看到同步画板和简单答题区。系统记录答对者并计分；教师可提前结束或进入下一轮。

### 重要限制 / Limitations
- 这是局域网 **Node.js 实时课堂原型**，不是已部署的公网网站；不支持在静态网页托管上直接联网。
- 服务器运行期间房间和分数暂存内存；重启后失效，无账号、持久化、教师身份验证或生产级安全措施。
- 房间码和参与者 token 在示范环境中使用，未配备 TLS、登录、反滥用及生产防护；**仅在受信任的课堂局域网演示**，不要直接向公网开放端口。
- 每轮 60 秒，最多 30 人/房间。刷新网页会失去当前身份，需重新加入；暂不支持断线身份恢复。
- 第一课和第二课目前是按学习知识点原创编写的演示词库，并非教材全文。
- 多人画板只保留单色笔、清空按钮；作画、答案、得分实时同步。没有实时聊天或公开排行榜。

## 规划 / Roadmap
- 增加教师课包编辑、拼音难度分级、随机选画手和更丰富的题库。
- 增加可靠的断线恢复、服务器持久化与更灵活的计分。
- 进入正式线上部署前：学生隐私保护、教师身份认证、服务端房间授权、HTTPS、访问频率限制、日志政策及学校审批。
- 原创教学内容，避免在公开网站直接复制教材课文、图片及扫描页面。
