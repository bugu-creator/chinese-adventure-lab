# 中文冒险岛 · Chinese Adventure Lab

V2.0 Homepage Foundation，在 V1.1 原生 Node.js 课堂原型上渐进升级。生产托管继续使用 GitHub + Render，不迁移现有多人服务。

## 运行与验证

需要 Node.js 18+，无需安装依赖。

```sh
npm start
# http://localhost:3000
npm test
```

Render 使用 `node server.js` 启动，监听平台提供的 `PORT`。先在开发分支完成检查并通过 PR 审阅，再合并 main 触发已有的 Render 自动部署。此仓库未包含 Render 部署配置，自动部署是否开启需要在 Render 控制台确认。

## 页面和目录

- `index.html`：冒险主题首页，学生、教师、公开学习者入口。
- `learn.html`：保留 V1.1 课程、朗读、拼音显隐、配对、问答与卧底游戏。
- `multiplayer.html`：保留教师创建房间、学生加入、实时绘画和答题界面。
- `assets/css/home.css`：首页设计变量、卡片与响应式布局。
- `assets/js/catalog.js`：首页课程、游戏目录与未开放功能说明。
- `assets/js/home.js`：目录渲染、建设中对话框。
- `assets/images/adventure.svg`：原创本地冒险插画，无外部图片请求。
- `server.js`：原生 HTTP 服务、显式静态资源路由、多人 SSE API。
- `tests/platform.test.js`：路由、MIME、导航、加入请求、游戏权限与计分回归测试。
- `docs/phase-1.md`：变更说明、验证边界与后续建议。

课程深链接：`/learn.html?lesson=l2&step=read`。可用 lesson 为 `l1`、`l2`；step 为 `intro`、`read`、`match`、`quiz`、`games`、`spy`、`draw`、`teacher`。无效参数回退到默认课程和页面。

## 当前可用

两个原创示例课包：数字和朋友、日期和生日。单设备朗读、词汇匹配、五题问答、传递设备查看卧底词语。多人你画我猜支持四选一与中文输入，服务器内存保存房间和分数。

首页不展示虚构百分比、金币或等级。宠物、文化地图、班级任务、账号和报告均标注建设中。身份入口只是功能导航，不是认证或授权。

## 多人课堂

1. 教师打开 `/multiplayer.html`，选择课包并创建房间。
2. 至少两名学生在各自设备访问同一服务地址，用六位房间码和课堂昵称加入。
3. 教师选择四选一或中文输入，开始游戏。
4. 系统轮流指定画画者，猜词者看实时画板并答题；每轮 60 秒，答对 +10 分。
5. 教师可以结束本轮或进入下一轮。

请使用受信任的教学环境和课堂昵称。单设备课程可直接打开 `learn.html`；多人游戏必须运行 Node 服务。

## 原型限制

没有数据库、真实账号或教师认证。房间最多 30 人，8 小时后移除，重启后失效。刷新会失去当前身份，尚无身份恢复。单设备课程进度仅存在当前页面内，不跨页面或设备持久保存。

当前多人原型未增加认证、反滥用或生产安全措施；现有 Render 地址不代表已具备正式公开服务条件。正式公开前需完成权限、隐私、稳定性和真实课堂设备验证。不要使用真实学生资料。浏览器设备语音可用性依赖设备。

所有教学内容应原创或已获授权，不上传教材扫描页、原版课文或受版权保护的插图。
