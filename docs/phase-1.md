# Phase 1 · Homepage Foundation

## 实现

暖色文化冒险首页、原创 SVG 熊猫与文化景观、课程目录、四个游戏直达入口、身份导航、宠物与地图概念预览、教师课堂工具入口和建设中对话框。CSS 使用统一颜色、圆角、阴影变量，布局覆盖桌面、平板和手机断点，支持触控、键盘焦点、跳过导航和减少动态效果偏好。

原 index.html 完整保留为 learn.html；仅增加返回首页及白名单校验的课程/关卡深链接。多人游戏只增加返回首页，并修复请求对象中 session room 覆盖用户输入 room、导致加入失败的问题。服务端多人状态与游戏规则保持原实现，仅增加显式静态文件路径及 MIME 类型。

## 部署范围与风险

保留 GitHub + Render 架构，不创建另一份托管站点。开发分支和 PR 不改变线上页面。合并 main 可能触发现有 Render 自动部署，并使正在进行的内存游戏房间因重启丢失；建议在无课堂游戏时发布。此阶段没有引入数据库或认证，教师入口不提供身份安全保障。
