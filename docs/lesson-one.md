# 第一课「数字」教师草稿

## 访问和内容边界

`npm start` 后访问 `/numbers.html`；首页教师中心新增“第一课「数字」· 教师草稿预览”。不会替换旧版学习入口，也不改变原多人 API、词库或课堂房间。新页面是教学预览，所有新记录均为 `draft`，不能在网页中批准或发布。预览确认提示不是教师身份认证；生产 Node 原型仍无权限系统，不应当作安全访问边界。

只实现 L01；不生成其他 14 课正式页面。用户提供的参考包仅用于目标、词汇与活动结构，未复制教材书页、课文、插图或录音。

## 课包与模块

- `data/lessons/L01.json`：原创材料、稳定 ID、审核状态和适配游戏标记。18 个词条含一到十、数量句型词以及十一、二十、三十。
- `assets/js/lesson-core.mjs`：共享词汇查询、洗牌、角色分配、任务锁定、一次性奖励和答案规范化。
- `assets/js/numbers.mjs`：课包加载和七个关卡的交互，不将学习题目硬编码在 HTML。
- `numbers.html` / `assets/css/lesson.css`：可复用页面壳及响应式组件。

课程数据包括 vocabulary、readings、sentences、matching、comprehension、quizzes、game_prompts 和 assessments。游戏引用词条 ID：数量图由数字值生成；卧底引用两词 ID；画猜引用答案和三个干扰项 ID。抽象词不可进入画猜池。

## 体验流程

1. 朗读：设备语音、拼音显隐、教师示范四声、两项自查。
2. 配对：一至十分两组配对数量图，错误反馈并允许重试。
3. 句型：原创数量句与提问、两道理解题、同伴口语自查。
4. 问答：五题，每题 20 秒，含数量、句子、组合数字和设备语音听辨；超时讲解，不扣分。最终显示正确率。
5. 卧底（可选）：3–12 人共用设备，逐人私看、隐藏再传递、讨论投票与揭晓。
6. 画猜（可选）：共用设备，秘密题面 → 隐藏 → 触控绘画 → 四选一或中文输入。60 秒计时；不显示题面给猜词者。不是线上多人新版本。
7. Exit Ticket：一道客观题、一句数量表达、口语和纸笔自查。客观题自动反馈，句子与口语/书写质量待教师评价。

默认自由复习；教师预览可启用顺序锁定。五个核心任务为朗读、匹配、句型、问答、Exit Ticket；两个游戏可选。XP 按任务首次完成发放，答错不扣分；完成问答或 Exit Ticket 不代表达到语言掌握标准。

进度仅在页面内存；刷新清空。Exit Ticket 可下载匿名 Demo JSON，由教师线下检查，不上传服务器。请使用虚构数量，不输入真实姓名。完成状态是自查/活动提交，不是正式教师成绩。

## 教师审核

逐条检查拼音/轻声、词汇范围、句型自然度、四选一干扰项、卧底中文描述难度、可画数量任务和时间限制。听力题脚本以 audio_vocabulary_id 关联词汇，设备语音失败时由教师朗读。口语不自动识别评分，纸笔先横后竖等提示不替代规范书写指导。

状态流程保留 `draft → teacher_reviewed → published`，但本阶段不实现身份、审核后台或发布机制。不能仅修改浏览器状态就变成正式课程；审核记录与受控发布需后续明确实现。

## 后续复用

第一课经测试和教师确认后，才增加 L02。新课沿用稳定 ID 和 schema，先编写 draft 数据与对应引用校验，再将页面入口参数化；不要直接批量生成未核验拼音或正式学生题库。后续若连接多人服务，只允许受控发布的课包进入学生房间，并在服务端隔离秘密答案。

## 初学者语言支架

题干、操作说明和概念分类词（如地点、数量、时间）超出已学范围时，必须提供英文或中英双语支持。此类概念选项优先直接使用英文。待测词本身保留中文，避免将正确答案直接翻译掉；中文干扰项应使用学生已学的词。拼音隐藏只影响拼音，不能移除必要的英文说明。课包通过 `prompt_en`、`instruction_en` 与 `language_support` 记录这一原则，供后续课次沿用。
